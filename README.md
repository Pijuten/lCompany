
# Project Title

Setup 

1. Download Lethal company from steam
2. Download [BepInEx](https://thunderstore.io/c/lethal-company/p/BepInEx/BepInExPack/) and extract to root game directory
3. Run game to generate Files
4. Add 

```bash
root/Lethal Company_Data/Managed/Assembly-CSharp.dll
root/Lethal Company_Data/Managed/UnityEngine.dll
root/Lethal Company_Data/Managed/UnityEngine.CoreModule.dll
root/BepInEx/core/BepInEx.dll
root/BepInEx/core/0Harmony.dll 
```
as reference to the editor

5. Add 
```bash
root/Lethal Company_Data/Managed/Assembly-CSharp.dll
```
to the decompiler for reversing game code
